## 三、时序图生成方式（诚实标注）

本机环境检查结果：

- `mmdc`（mermaid-cli）：**未安装**；
- `dot`（graphviz）：**未安装**；
- `node` v22.22.2、**Python 3.13 + PIL 13.0.0**、Microsoft Edge 均可用。

因此采用以下方式生成 PNG，未安装任何新软件：

1. 先按 Mermaid 语法编写 `.mmd` 源文件，作为图的标准描述；
2. 用 Python 以纯文本方式生成对应 `.svg` 矢量源图（含参与者框、生命线、实线/虚线消息箭头、序号与说明框）；
3. 使用 **Microsoft Edge 无头模式**（`msedge.exe --headless --screenshot --window-size`）将 SVG 渲染为 PNG；
4. 用 Python PIL 复核 PNG 尺寸，并用图像查看确认中文渲染与布局完整。

说明：PNG 由 SVG 经 Edge 渲染得到，而非 `mmdc` 直接渲染 `.mmd`；`.mmd` 与 `.svg` 内容一一对应。本机未安装 mermaid-cli 与 graphviz，故采用该方式，且全程未安装新软件。

四张 PNG 实测尺寸：客户添加 1516×883、客户删除 1240×829、客户编辑 1284×937、多员工添加 1240×721。
